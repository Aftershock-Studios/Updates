# Asset Marketplace & Studio Menus

- Browse the online Poly Haven catalog of free CC0 3D models and PBR materials.
- Search and filter assets; select up to 12 items in the download cart, remove items or review source pages.
- Native macOS batch download progress, background imports, checksum validation, per-asset error handling, Cancel and Restart Now / Restart Later.
- Downloaded assets persist in project storage; models appear in Project Library and materials can be applied to existing world-material slots.
- Source and attribution metadata retained for imported assets and exported games.
- Reorganised native macOS menus: Project, Transform, Scene, Assets, View and Updates. Play/Stop, asset buttons and essential viewport controls remain in Studio.
- Existing assets and projects remain compatible; no automatic asset downloads.
- First integrated provider: Poly Haven (CC0). Other Creative Commons licences/providers are not automatically supported yet. HDRIs, rigged character animation and arbitrary URL downloads are not included.
- Requires v0.0.21. 211 automated CPU-side tests passed; 11 native tests skipped. Native macOS UI and live provider importing require hardware testing.
