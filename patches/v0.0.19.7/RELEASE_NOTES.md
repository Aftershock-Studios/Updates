# Living World

- Randomized startup loading messages, including coffee, world population and digging holes.
- Optional native startup-screen refresh with an original-launcher backup and restore option.
- More detailed procedural character faces, skin shading and layered hair tufts that move in the wind.
- Persistent-in-session rain wetness, reflective puddles, raindrop ripples and gradual evaporation driven by sunlight and wind.
- Six-band detailed ocean normals, underwater color attenuation, basic swimming (Space to ascend, Control to dive), drag and density-aware approximate collider buoyancy.
- Dedicated Graphics settings with individual material, cloud, water, grass, weather, shadow, ambient occlusion, hair, antialiasing, skinning, resolution and lighting controls; save preferences for the next launch.
- Import real 1K scanned PBR material maps into the project, with game export support.
- Native update dialog shows the release name, target/current version, download size and scrollable release notes.

Compatibility: v0.0.19.6. Built-in characters and textures are procedural; scanned material packs are imported separately. Puddles and water physics are approximations, not a full fluid solver. The optional launcher refresh requires an unsealed local developer app and Xcode command-line tools.
